# محافظ بسيط | Mohafez Baseet

Quran memorization platform built with React.js + Node.js.

## Quick Start

```bash
# Install dependencies
cd backend && npm install
cd ../frontend && npm install

# Start everything
bash start.sh
```

- Frontend: http://localhost:3000
- Backend API: http://localhost:5001

## Features
- 📖 Full Quran text (114 surahs) via alquran.cloud API
- 🎧 Audio recitations by 4 reciters (Alafasy, Minshawi, Husary, Abdul Basit)
- 🔖 Bookmarks per ayah (requires login)
- 📈 Memorization progress tracking per surah (requires login)
- 📥 Download management (requires login)
- 🌙 Dark/Light mode
- 🌐 Arabic/English bilingual (RTL/LTR)
- 🔐 User accounts with JWT auth
